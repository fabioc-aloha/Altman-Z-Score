# Altman Z-Score Project - IUPAC Systematic Element Naming Convention

## Systematic Element Naming Strategy

The Altman Z-Score project adopts a systematic naming convention for version numbers based on IUPAC rules for hypothetical chemical elements. This provides unique, memorable, and scientifically-inspired names for each version, originally developed for the NEWBORN Cognitive Architecture.

### Input
An integer representing the version number converted to atomic number format (e.g., version 0.0.1 → 001, version 0.0.2 → 002).

### Output
A made-up element name using IUPAC systematic naming rules.

## Naming Rules

1. **Convert each digit** of the number into a Latin/Greek root:
   - 0 = "nil"
   - 1 = "un"
   - 2 = "bi"
   - 3 = "tri"
   - 4 = "quad"
   - 5 = "pent"
   - 6 = "hex"
   - 7 = "sept"
   - 8 = "oct"
   - 9 = "enn"

2. **Concatenate the roots** in digit order and append "ium"

3. **Remove duplicate vowels** at root boundaries (e.g., "ennnil" → "ennil")

4. **Drop final "i"** if the last root ends in "i" and is followed by "ium"

## Dual Naming System Explanation

The Altman Z-Score project uses a **dual naming system** for comprehensive version identification:

### 1. IUPAC Element Names (Technical Precision)
- **Purpose**: Unique, systematic identification of exact version numbers
- **Format**: Based on IUPAC systematic element naming rules
- **Example**: Version 5.0.0 → PENTNILNILIUM
- **Usage**: Technical documentation, code comments, precise version references

### 2. Release Series Names (User Communication)
- **Purpose**: Marketing-friendly names for major version families
- **Format**: Gemstone/Material names for version families
- **Example**: Version 5.x.x → EMERALD Series
- **Usage**: User-facing documentation, release announcements, marketing materials

### Combined Usage
- **Full Format**: "v5.0.0 PENTNILNILIUM – EMERALD Release Series"
- **Benefits**: Technical precision + marketing appeal
- **Clarity**: Exact version + broader context
