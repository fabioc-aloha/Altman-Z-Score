# Version 3.4.2 Release Summary

## 🎯 Main Feature: Actionable README Table

The README portfolio table now includes an **"Investor Advice"** column that automatically extracts investment recommendations from each company's Z-Score report, making the README immediately actionable for investors.

## ✨ Key Improvements

### Enhanced Portfolio Table
- **📈 BUY** recommendations with ratios (e.g., "BUY (4/6)")
- **⚖️ HOLD** recommendations for neutral positions  
- **📉 SELL** recommendations for high-risk companies
- **📊 MIXED** recommendations with breakdowns
- **❓ No Data** indicator for parsing issues

### Smart Extraction Logic
- Automatically parses investor recommendation tables from reports
- Extracts recommendation summaries when available
- Falls back to counting individual recommendations
- Robust error handling for various report formats
- Clear visual indicators using emojis

### Example Output
| Company | Investor Advice |
|---------|----------------|
| Microsoft Corp | 📈 BUY (Most Profiles) |
| JPMorgan Chase & Co | 📊 MIXED (0B/3H/3S) |
| Apple Inc | 📈 BUY (4/6) |
| Carnival Corp | 📉 SELL (3/5) |

## 🚀 How to Use

```bash
# Generate/update the README table with investor advice
python generate_readme_table.py
```

The script will:
1. Scan all reports in the `output/` directory
2. Extract investor recommendations from each report
3. Update the README table with the new "Investor Advice" column
4. Provide immediate investment guidance alongside existing data
