## Z-Score Formula Used (Original Z-Score (Public Manufacturing, 1968))

Z = 1.2*X1_WC/TA + 1.4*X2_RE/TA + 3.3*X3_EBIT/TA + 0.6*X4_MVE/TL
- X1_WC/TA = (Current Assets - Current Liabilities) / Total Assets
- X2_RE/TA = Retained Earnings / Total Assets
- X3_EBIT/TA = EBIT / Total Assets
- X4_MVE/TL = Equity / Total Liabilities

**Thresholds:**
- Safe Zone: > 2.99
- Grey Zone: > 1.81 and <= 2.99
- Distress Zone: <= 1.81
